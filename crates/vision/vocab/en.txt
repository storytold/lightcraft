# LightCraft content vocabulary, English. Original work written for LightCraft (MIT OR Apache-2.0 like the rest of
# the repository's own files); not derived from any published label set.
#
# One tag per line:   path|of|the|tag                  the photo is described by the last level ("tag")
#                     path|of|the|tag = a, b, c        described by a, b and c (synonyms: one tag, their prompts are
#                                                      averaged); typing any of them finds the tag
#                     … @0.05                          this tag's own cut-off instead of the model's
# Levels above a tag need no line of their own: a photo tagged `animal|bird|owl` also counts under `animal|bird` and
# `animal`. A level with a line is a tag of its own as well. `#` starts a comment.
