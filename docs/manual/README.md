# User manual

> Names in angle brackets (`<app>`, `<binary>`, `<cli>`, `<PREFIX>`, `<settings_dir>`, `<catalog_ext>`,
> `<library_default>`) are the values set in [`brand.toml`](../../brand.toml). `Cmd` means ⌘ on macOS and `Ctrl` on
> Linux, Windows and the web.

<app> is a photo library and non-destructive raw developer laid out like Lightroom Classic: one catalog, seven
modules, and every action a command you can also run from the command line, a script or an AI agent.

1. [Getting started](getting-started.md): install, first launch, first import, first export.
2. [The modules](modules.md): Library, Develop, Map, Book, Slideshow, Print, Web.
3. [Catalogs](catalogs.md): where your library lives, backups, moving photos between catalogs.
4. [Import and export](import-export.md): import, export presets, the command-line renderer.
5. [Publish services](publish.md): keep a folder (or an Immich server) in step with a collection.
6. [Tethered capture](tethering.md): studio sessions from a watched folder.
7. [Immich](../immich.md): link, sync and import with an Immich server.
8. [Plug-ins](../plugins.md): WebAssembly plug-ins, their permissions and how to write one.
9. [Edit In and Actions](edit-in-and-actions.md): round trips to other editors, recorded command sequences.
10. [Keyboard shortcuts](keyboard-shortcuts.md) (generated by `cargo xtask shortcuts`).
11. [Troubleshooting](troubleshooting.md).
12. [Migrating from Lightroom Classic](migrating-from-lightroom.md).

Reference: [control protocol](../control-protocol.md), [MCP](../mcp.md), [XMP interop](../xmp-interop.md),
[process versions](../process-versions.md), [packaging](../packaging.md), and the [parity tracker](../parity.md)
(what matches Lightroom, and what doesn't yet).
