# 0.8.0

**If you're on 0.7.2 or earlier, download this release manually once; automatic updates work from 0.8.0 on.**

Changes since 0.7.2: this release merges upstream's `main` (upstream release 0.7.1 and its "batch 32", 257
commits since the last merge at upstream 0.7.0). After each item, the matching upstream pull request:
`(↑ #n)` means the maintainer of this fork opened it upstream, `(⇠ #n)` means the fork had already ported it,
and `(no PR)` means there is none. Every item below is merged upstream unless it says otherwise.

## Highlights

- **Kelvin White Balance like Lightroom:** the Temp slider has Lightroom's scale (7000 K in the middle), and Sony
  raws read their Kelvin white-balance presets. (#1295)
- **Render to DNG** export format, and **HLG HDR AVIF** export. (↑ #1047, ↑ #1017)
- **Large preset collections** (10 000+ presets) no longer stall commands, frames or the Presets panel. (PERF-PRESETS)
- **Raw fixes:** CR2 white level from the active area (#1272), PowerShot G9 and Olympus E-10 as-shot white
  balance (#1273), Pentax PEF masked borders (#1271), Nikon D90 filler columns, Nikon D7100 frame (#1248), EOS
  R6 Mark III white balance, Hasselblad Lunar and uncompressed Leaf MOS (#1275), DNG CFA pattern at the active
  area.

## Develop and viewing

- History cursor: going to a step adds no step. (⇠ ↑ #1246; upstream's version now used)
- The HDR histogram follows slider drags live; the tone curve shows the histogram behind it.
- ⌥-drag moves a curve point a tenth as far (#1363); Cmd/Ctrl and Alt modifiers on the colour wheels (#1160).
- A crop shrunk by Straighten grows back (#1388); in-camera crop modes get the frame's crop factor for lens profiles.
- The loupe and Compare say "Rendering…" while a stand-in is shown, and when a render failed.
- With a GPU, a slider drag's preview is drawn in the same frame; the edited photo's thumbnail is not decoded
  during a drag; the Detail photo's original stays decoded over the memory budget.
- Ctrl/Cmd+O shows every mask overlay at once; F6 / F7 panel toggles.
- Preset Amount no longer undoes unrelated edits.
- Camera-look deep shadows follow the camera JPEG's toe (#1307).

## Library and import

- Up / Down move through the grid's rows. (⇠ ↑ #1264)
- Deleting asks first, also from the right-click menu; the setting is saved under a new key (#1239).
- New Album can include the selected photos (#1249); an album's Import submenu (#1267).
- Metadata-less exports import with the file's date. (⇠ ↑ #1216)
- Locate missing files by folder tree (#1194); Recently Deleted files can be re-imported by hand (#1285).
- HEIC, HEIF and NRW are imported from folders; symlink aliases are not scanned twice.
- Faster left panel with a large keyword list (#1011).
- Read Metadata from File no longer auto-writes the sidecar it just read (#934).
- Photo ▸ Edit In ▸ Open Original in Other Editor (RAW, no copy); several files open in one start of the editor.
- Transparent areas develop on white (#1212).

## Platform, accessibility and translation

- AccessKit tree audit: text fields named, sliders expose their range. (↑ #1023; the fork's own port kept)
- A notice when no GPU is found. macOS: closing the window ends the process (#1331).
- `--connect 7980` takes a bare port (#1178); the control channel gives up requests a hidden window can't
  answer. (↑ #1070)
- Translations: Compare captions, curve menu, Remove panel, Local menu, Photo Merge, masking menu, Spanish and
  Brazilian Portuguese face recognition strings. (⇠ ↑ #1291, #1292, #1293, #1294, #1270)
- CPU ↔ GPU equivalence verified on an AMD Radeon 8060S. (↑ #1094)

## Kept from the fork instead of upstream

- Linux display profile: the fork's X11 `_ICC_PROFILE` + colord reader (and the Windows WCS reader) is kept;
  upstream's colord-only version (↑ #1051) is a subset and was dropped.
- Zoomed views: the fork's tiled region renderer is kept; upstream's per-pane zoom windows for Compare and their
  tests were not taken.

## Fork-side changes since 0.7.2

- **Develop has Classic's left column:** Navigator, Presets, Versions, History and Collections, like Lightroom
  Classic; upstream's My Photos column stays available as a hidden panel. Thanks @deunderscorepaul. (fork PR #39,
  fixes fork issue #5; no upstream PR)
- **Recently Deleted can be emptied:** an Empty button and a sidebar menu item, both asking first. (fork PR #32;
  no upstream issue)
- **"Don't Import Suspected Duplicates"** checkbox in the Import dialog. (fork PR #32; ↑ #1552, open, refs #1401)
- **Large Lightroom catalog imports no longer stall:** stamping XMP sidecars was quadratic in the number of photos
  (8 000 photos: about 100 s → 3 s), and Read Metadata from File on a large selection had the same problem
  (20 000 photos: 98 s → under 1 s). (fork PRs #33, #38; no upstream PR)

## Release builds

- The FreeBSD, Linux riscv64 and Windows x86 builds are no longer published. (no PR)

## Fixes

- Auto-update now works — the update check always failed with a 404 in 0.7.2 and earlier. (fork PR #30, no upstream PR)
