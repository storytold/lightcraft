# 0.9.0-rc1

The first release candidate for 0.9.0: everything since 0.8.2, plus two upstream merges (about 560 upstream
commits). After each fork item, the matching upstream pull request: `(↑ #n)` means the maintainer of this fork
opened it upstream, `(⇠ #n)` means it was ported from an open upstream PR, and `(no PR)` means there is none (no
upstream issue, or the change is in the fork's own Classic layout). Items under **From upstream** came in with the
merges.

> [!IMPORTANT]
> This is a release candidate. The catalog format moves to version 12 (preview-only photos record the app version
> that checked them, and the camera's focus point is kept). 0.9.0-rc1 opens older catalogs and upgrades them;
> 0.8.x can't open a catalog once 0.9.0-rc1 has saved it. Back up your library before trying it.

## Highlights

- **Upstream merged:** two upstream batches (through upstream's batch 40) with a long list of features and fixes,
  below. The fork's Classic layout is kept, upstream's work folds in around it.
- **Lightroom Classic layout, closer:** each module has its own tool strip, the left column ends in Import… /
  Export… (Library) or Copy… / Paste (Develop), the Edit panel opens with Auto · B&W · HDR, Reset sits in the bottom
  bar, and Identity Plate Setup personalises the module bar. Thanks @rampar20 and @deunderscorepaul for the reports
  and patches.
- **Colour readout in RGB, HSL or Lab** under the histogram, and on colour pickers. (no PR)
- **No freezes from network shares:** disk folders and XMP sidecars are looked at off the UI thread. Thanks
  @endthestart. Fork #123. (no PR)
- **Delete from Disk** (to the system trash, always asked first). Thanks @deunderscorepaul. Fork #98. (no PR)

## Develop

- **Colour readout in RGB, HSL or Lab:** with the pointer on the photo, its colour shows under the histogram as
  R / G / B %, HSL or CIE L\*a\*b\* (D50), picked in the histogram's right-click menu or View ▸ Color Values and
  remembered; colour pickers and Point Color swatches show all three on hover. Maintainer request. (no PR)
- **Draggable histogram:** the plot's five tonal zones — Blacks, Shadows, Exposure, Highlights, Whites — are live again,
  as in Lightroom Classic. Hovering one tints it and shows its value under the histogram ("Exposure: +0.45 EV"); dragging
  one sideways moves that Basic control, with the zone the press landed in locked for the whole drag (Shift a tenth as
  far, as on the sliders) and the whole drag one undo step; double-clicking a zone puts its control back to its default.
  Maintainer request. (no PR)
- **Treatment buttons:** the Edit panel opens with Classic's button row: Auto, B&W (a toggle) and HDR. The separate
  Treatment row is gone and Auto moved up from the Tone heading, so the Basic sliders start higher up the column.
  Thanks @rampar20. Fork #124. (no PR)
- **Reset at the bottom of the Develop panels:** beside Previous / Sync…, as in Lightroom Classic. Thanks @rampar20.
  Fork #116. (no PR)
- **Clipping shown on the photo:** J / the histogram triangles paint clipped highlights red and crushed shadows blue
  per pixel, and ⌥/Alt-dragging Exposure, Highlights, Whites, Shadows or Blacks shows Lightroom's black / white
  clipping mask. Thanks @deunderscorepaul. Fork #94. (no PR; upstream has #995 / #999 for the same, open)
- **The mouse wheel resizes the brush** while masking (Ctrl/Cmd+wheel still zooms; a setting turns it off). Thanks
  @deunderscorepaul. Fork #96. (no PR)
- **Tidier Masks panel:** Refine Edges and Feather under the overlay Opacity; Show all overlays and Show Pins on the
  overlay-colour row. Thanks @deunderscorepaul. Fork #91, issue #82. (no PR)
- **The Presets panel folds away** under the same Classic header as the panels below it. Thanks @deunderscorepaul.
  Fork #75. (no PR)
- **Vivid colour grading wheels:** the rim is fully saturated, fading evenly to a neutral centre. Fork #77.
  (↑ #1719)

## Library

- **Each module has its own tool strip:** Develop's shows its editing tools (Presets, Edit, Crop, Remove, Masking,
  Red Eye); Library gets Versions and History & Activity, which open over its right column. Thanks
  @deunderscorepaul. Fork #114, issue #108. (no PR)
- **Import… / Export… and Copy… / Paste under the left column**, outside the scroll. Fork #118. (no PR)
- **Identity Plate Setup:** Edit ▸ Identity Plate Setup… personalises the module bar's plate with styled text or your
  own SVG / PNG / JPEG logo, with a live preview. Thanks @rampar20. Fork #121. (no PR)
- **The first photo selected stays the active one** on ⌘/Ctrl- and Shift-click, so Sync Settings copies from the
  photo you picked first. Thanks @rampar20. Fork #119. (no PR)
- **Tethered Capture** sits after Import from Device in the File menu. Thanks @rampar20. Fork #120. (no PR)
- **Delete from Disk:** Photo ▸ Delete from Disk, or the button in the Delete dialog, moves the photos' files and
  sidecars to the system trash and takes them out of the library in one undo step. Thanks @deunderscorepaul. Fork
  #98. (no PR)
- **Search in the filter bar's pickers** (Camera, Lens, Keyword). Thanks @deunderscorepaul. Fork #105, issue #99.
  (no PR)
- **Filter by number of faces:** a Faces menu in the filter bar, `faces` in `library.filter`, the `faces:` search
  token and a Face Count smart-album rule. Thanks @deunderscorepaul. Fork #100. (no PR)
- **No freezes from folders on a network share:** the Folders panel lists disk folders, and the grid checks XMP
  sidecars for its badge, on threads of their own. Thanks @endthestart. Fork #123 (landed as #137). (no PR)

  (plus an optional subfolder), and a File Naming Template menu with Custom Name - Sequence, Filename - Sequence and
  the Custom Text token. Fork #80. (⇠ #996)
- **Canon EOS R6 verified:** its lossless CR3 files decode pixel-exact (five files checked). Fork #125. (no PR:

## From upstream

Selected from upstream's release notes (`docs/whats-new.md` has every entry):

- **Where the camera focused:** View ▸ Show Focus Point (⌥F) draws the camera's autofocus frame, and Z zooms to it
  (Sony α1 and A7S III for now); photos already in the library get theirs in the background.
- **Edits keep up in a large library:** a rating, flag, keyword or slider no longer re-works the grid, the side-panel
  tallies or smart-album counts from every photo; **View ▸ Hold View Until Refreshed** keeps edited photos in view.
- **Camera colour:** Nikon Z 6II, Z 8 and D5300 profiles (eight bundled profiles in all); closer colour for
  lens-corrected raws; Sony A7R VI lens distortion from the file; Nikon DSLR lens names.
- **Raw decoding:** more Canon EOS R6 Mark II C-RAW files decode; no edge bars on older Nikon bodies or a bright line
  on the D600 / D610 / D5000; popular Nikon, Fujifilm, Canon CR2 and Pentax bodies verified (596 models verified in
  all).
- **HDR and panorama merges:** HDR for Each Bracket Set, moving lights in night brackets, white balance kept,
  cleaner bright windows, a quarter less memory; full-resolution panoramas.
- **Slideshow:** templates (five built in), export to PDF, JPEG or AV1 video.
- **Brush:** ⇧-click paints a straight line; pen pressure where the system reports it.
- **Keywords panel:** folding sections, keywords grouped by parent, suggestions under Add keyword.
- **Smaller JPEG exports** (12–14 % at the same pixels); noise reduction looks the same at every size.
- **Window size remembered**, an Import button in the top bar, a layout image over the loupe, confirm matching
  faces together, Delete in an album removes from the album only, Lightroom radial masks on the right side.
- **Reliability:** a crafted raw can't make the app reserve gigabytes before failing; catalog saves and model
  downloads never write through a link at the temporary file's name; XMP sidecars catch up after a share comes back;
  one background thumbnail writer; GPU resets during export handled; non-ASCII capture dates no longer crash the
  date tree.
- **Languages:** Czech, Italian, Georgian and Polish catalogs from upstream; the fork's own strings in those
  languages are machine translations, not yet reviewed.

## Fixes

- **Delete from Disk on macOS:** on a case-insensitive disk an XMP sidecar was listed (and would be trashed) three
  times, once per spelling of `.xmp`. (no PR)
- **Tab keeps the focused control in view:** in the side panels, Tab scrolls a slider or button it moves to into
  view instead of focusing it off-screen; the panel resize edges and the Auto Sync switch are named for screen
  readers. (no PR)

## Development

- **Leaner test suite:** change-detector, duplicate and timing-probe tests removed across the workspace (about 5,400
  → 5,300); network, security and crash-safety tests kept. (no PR)
- **Tests never open desktop windows:** showing a file in the file manager and starting an external editor go
  through a session seam that headless runs record. (no PR)
- **Faster release uploads:** each platform job uploads straight to the draft release. (no PR)
