# 0.8.1

Changes since 0.8.0, mostly from user reports. After each item, the matching upstream pull request: `(↑ #n)` means
the maintainer of this fork opened it upstream, `(⇠ #n)` means it was ported from an open upstream PR, and `(no PR)`
means there is none (no upstream issue, or the change is in the fork's own Classic layout).

## Highlights

- **Preset Amount fades smoothly:** moving Amount down fades the preset gradually to 0 % (the photo as it was)
  instead of jumping to the unedited image below 50 %; curves blend point by point, and up to 200 % extrapolates.
  Fork #37. (no PR)
- **Large preset collections stay fast:** Quick Develop's Saved Preset menu, the tether bar's preset list and the
  painter's Settings list build only the rows in view (10 000 presets: 16 ms → 0.8 ms a frame with the menu open).
  Fork #36. (no PR; upstream's #1133 was already fixed by #1056)
- **Faster mouse-wheel scrolling:** a wheel notch scrolls a third of the grid or filmstrip, and **Preferences ▸
  Interface ▸ Wheel scroll speed** (Normal / Fast / Fastest) speeds it up further. Port of MarkusFriedel's upstream
  change. Fork #34. (⇠ #1482, open)
- **Faces on the GPU:** face detection and recognition run their convolutions on the GPU when a quick check shows it
  matches the CPU and is faster (AuraFace about 2–2.5× faster); the CPU stays the reference and the fallback. First
  step of fork #35. (↑ #1663, open)

## Library and import

- The photo right-click menu (grid, filmstrip, loupe, compare) has **Add to / Remove from Quick Collection (B)**
  (or the target collection's name when one is set) and follows Lightroom Classic's order: flag, rating, colour
  label, then collections, then file actions. Fork #46. (no PR)
- Long exposure times keep their step: 0.4 s, 0.8 s and 1.3 s are shown and exported as such instead of being
  rounded to 1/2, 1 and 1 s. Thanks @deunderscorepaul. Fork PR #41. (upstream issue #1619; no upstream PR yet)
- Import from `.xmp` sidecars beside raws: a regression test now covers rating, colour label, crop and develop
  settings (Add and Copy), and that Read Metadata from File never reverts your own later edits. We couldn't
  reproduce the reported loss; if your sidecar ratings or crops still don't come across, please add a sample to
  fork #43. (no PR)

## Interface

- Develop's tool strip shows only Develop's tools; Keywords and Info (Library panels) open from the Window menu and
  their shortcuts. Fork #45. (no PR)
- Folded sections of the Book, Slideshow and Map side panels stay folded after a restart, like the Classic panels,
  edit sections and Solo Mode. Fork #44. (no PR)
- The HDR button says when the window can't show HDR (it shows the SDR rendition, even on an HDR display; HDR
  exports keep the full range). Real HDR display output is in progress. Fork #47. (no PR)

## Development

- `cargo test -p lcc-ui-egui` runs the model-setup tests on its own (the crate's tests enable the engine's denoise
  feature). (no PR)
