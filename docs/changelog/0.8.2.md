# 0.8.2

Changes since 0.8.1, mostly from user reports. After each item, the matching upstream pull request: `(↑ #n)` means
the maintainer of this fork opened it upstream, `(⇠ #n)` means it was ported from an open upstream PR, and `(no PR)`
means there is none (no upstream issue, or the change is in the fork's own Classic layout).

## Highlights

- **HDR display output:** on an HDR display (Windows with HDR on, Linux KDE Plasma Wayland with HDR or EDR), an HDR
  edit shows its highlights above SDR white, up to what the display can show, while the interface stays at SDR
  white; SDR displays look as before. On Linux the headroom is read from the compositor. `--hdr-probe` reports what
  a machine offers. Checked on screen on Windows 11 (RTX 4090) and Linux (KDE Plasma 6.7, laptop panel with EDR);
  **macOS EDR is built but not yet checked on screen.** Fork #47. (↑ #1700)
- **Faces run wholly on the GPU:** YuNet, SFace and AuraFace are 3–4× faster than on the CPU; Settings ▸ Faces shows
  the device and can keep them on the CPU, and the scan pace limits GPU use. Fork #35. (↑ #1663)
- **Sharpening Radius and Detail work:** sharpening is an unsharp mask at the Radius (in the photo's own pixels, so
  previews and exports match), and Detail damps or keeps halos. New process V4: photos edited before keep their look
  until Update to Current Process (or Reset). Port of radialmonster's upstream change; user report on a Nikon Z5II.
  (⇠ #762)
- **Crop & Straighten:** the crop box stays put and upright while the photo turns and slides beneath it, as in
  Lightroom Classic, and straightening or moving no longer re-renders the photo on every step. Fork #60. (↑ #1699)

## Develop

- **Basic panel in Lightroom Classic's order:** Treatment (Color / Black & White) and Profile, then the WB row,
  Temp and Tint, Tone with its Auto button, and Presence (Texture, Clarity, Dehaze, Vibrance, Saturation). Fork #46.
  (no PR)
- **HDR edits' SDR version keeps its highlights:** thumbnails, the Navigator, SDR exports and the loupe on SDR
  displays roll an HDR edit's highlights off smoothly instead of clipping them; SDR edits are unchanged. Fork #69.
  (↑ #1697)
- **Typing a slider value:** clicking a slider's value opens the field however long the click is held (a slow click
  used to close it again), and dragging the value sideways scrubs it. Fork #59. (↑ #1687)
- **Sync Settings like Lightroom Classic:** Photo ▸ Develop Settings ▸ Sync Settings… (Shift+Cmd/Ctrl+S) opens
  Synchronize Settings, which can now carry single Basic Tone sliders (e.g. only Exposure). Create Version loses that
  shortcut. Fork #61. (no PR)

## Interface

- **The Navigator stays in place** at the top of Library's and Develop's left column while the panels below it
  scroll. Thanks @deunderscorepaul. Fork #76. (no PR)
- **Clicking the tool in use** on Develop's tool strip leaves it open instead of closing it and dropping back to the
  grid (radio-style, as in Lightroom Classic). Thanks @deunderscorepaul. Fork PR #78. (no PR)
- **Folded panels stay folded:** a saved panel layout the app can't restore no longer stops all settings being saved
  for the session (and so at every launch); the original file is kept aside. Fork #44. (no PR)
- The wheel scroll speed setting (0.8.1) is translated into all languages. (no PR)

## Import

- Import finds a sidecar whose photo extension or `.xmp` differs in case (`DSC_1.nef.xmp`, `DSC_1.Xmp` beside
  `DSC_1.NEF`) on case-sensitive disks, so its rating and crop come in; Move takes it along. Fork #43. (↑ #1686)

## Release builds and CI

- Every build and test now runs on the project's own machines (Linux, macOS, Windows x64 and Windows on ARM; Windows
  ARM64 is now built natively).
- **The Flatpak download is paused for this release** (its build check needs a fix in the new CI containers); the
  AppImage, deb, rpm and tarball are unaffected. It returns in 0.8.3.
- **Linux ARM64 (aarch64) downloads are paused** (AppImage, Flatpak, deb, rpm, tarball); `packaging/linux/package.sh
  aarch64` still builds one locally.

## Upstream merge

This release merges upstream's `main` (its integration "batch 35", upstream #1682: 71 commits since the last merge).
Every item below came from upstream; issue numbers are upstream's.

### Develop and viewing

- Nikon Z 6II, Z 8 and Z f NEFs use the camera's own distortion correction.
- HDR merges keep the reference frame's lens correction.
- Heal and Clone spots with Feather at 0 no longer draw black pixels on their radius; spots at 0% opacity change
  nothing.
- The all-masks overlay shows the union of the masks, not only the last one.
- A zoomed view with Dehaze keeps its haze estimate while panning and dragging sliders (faster zoomed edits).
- The Before/After button no longer lights up for Show Original (`\`) (#1497); the loupe's filter pill is evenly
  inset (#1645).

### Library, import and files

- Edit ▸ Select Only Active Photo (⌘/Ctrl+Shift+D).
- In Compare, ⌘/Ctrl- and Shift-clicks on the filmstrip change the selection without replacing the pair.
- Clearing the filters empties the search field too (#1648); an import ends showing its first photo (#1446);
  Synchronize Folder in the Local folder menu; Recently Deleted lists deleted Local photos (#1430).
- Thumbnails decode the smallest embedded JPEG that covers them, and a raw whose embedded preview can't be read still
  gets a thumbnail (#1448).
- Scans, imports and sidecar writes no longer build a table of the whole library first (large libraries start sooner).
- Face pictures in the People view come from the embedded preview and are cached (#1440).
- Lightroom Classic catalogs whose tables are all still in the `-wal` file open; ARW6 files are described from the
  whole file.
- DNG export and Convert to DNG no longer repeat the camera make in the model name (#840).
- **Portable mode:** a `portable.txt` (or `<binary>.portable`) file next to the program keeps settings, logs and
  models in a data folder beside it (#1200).
- Canon EOS RP CR3 verified pixel for pixel.

### Reliability (never crash)

- Damaged catalog snapshots are repaired on open; open / new library is refused while an import runs (#1509); moved
  originals are re-checked before deletion (#1500); name reservation falls back to an exclusive create where hard
  links are unavailable (#1503).
- Fixed panics or hangs for: defringe amounts past the sliders, huge spot sizes (#1519), zero-size and sliver crops,
  close tone-curve points, `mask.move` with a huge delta, NaN black levels, very long export strips, enlarged exports
  (capped at 512 MP), preset zips that unpack too far, BigTIFF IFDs with huge entry counts (#1516), NEF / PEF Huffman
  predictor overflow (#1515), truncated PEF streams (#1514), RAW TIFFs with missing chunks (#1513), raws with two
  samples per pixel (#1511), non-finite denoise pixels, bad ONNX LeakyRelu alphas (#1530) and SAM weight shapes
  (#1529).
- The preview disk cache ignores symlinked shard folders (#1504); downloads refuse an https → http redirect (#1531).
- MCP in connect mode no longer resends a request whose reply was lost (#1526).
- Malformed settings groups in Copy / Paste / Sync Settings are refused with a message.
- The Windows installer ends with a completion page after install, repair and uninstall (#892).
- The interface decides on error kinds (missing model, cancelled) instead of English error text (#1046).

### Translation

- Brazilian Portuguese: AI Denoise translated, plurals and six strings fixed.

### Kept from the fork instead of upstream

- Zoomed views: the fork's tiled region renderer stays; upstream's zoom-window tests and the `ZOOM=` mode of the
  `drag_latency` example were not taken.
- Catalog: the fork's catalog stays; upstream's snapshot repair, exclusive-create reservation and Recently Deleted
  fix were ported by hand.
- Portable mode and the DNG writer follow `brand.toml` (data folder and `<binary>.portable` marker named after this
  app; DNGs marked `<app> DNG 2`, older DNGs still read correctly).
- Sync Settings keeps the fork's single-control sync on top of upstream's group validation; Rename Photos stays in
  the Library menu.
