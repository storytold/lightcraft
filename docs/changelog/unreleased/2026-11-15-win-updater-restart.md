## Updater and security

- **Windows updates relaunch the app and keep Start-menu shortcuts working:** installing an update on Windows now runs a small helper that waits for the app to quit, runs the installer (so it no longer overlaps the running app), and starts the app again when the installer succeeds — exit 3010 (success with a reboot required) starts nothing, because Windows starts the desktop again after the reboot. The Start-menu shortcut the installer writes is a plain link to the installed program instead of an advertised shortcut: advertisements resolve through their product's registration, which every upgrade replaces, so Start-menu entries and taskbar pins stopped working after updates. Windows CI now packages a second, higher-version MSI, upgrades over the first on a real Windows and checks the shortcut resolves.
