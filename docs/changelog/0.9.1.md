# 0.9.1

The changes since [0.9.0](0.9.0.md). After each item, the matching upstream pull request: `(↑ #n)` means the
maintainer of this fork opened it upstream, `(⇠ #n)` means it was ported from an open upstream PR, and `(no PR)`
means there is none (the change is in the fork's own Classic layout or a fork issue with no upstream counterpart).

The catalog format is unchanged from 0.9.0 (version 12).

## Highlights

- **History you can edit in the past:** Develop's History groups consecutive edits by panel (Basic, Colour,
  Detail, …). Each group expands to its steps. Go back to any step and change a slider there: only the later
  steps in that group are replaced, and every later group is replayed on top, so later work isn't lost. Presets,
  pasted and synced settings are groups of their own, and *Return to Latest* takes you back. A rewrite is one
  undo step. Fork #215. (no PR: Classic's history panel)
- **Photo Merge, sharper and lighter:** handheld HDR merges are aligned at full size and tile by tile, and resampled
  with Lanczos-3. HDR Panorama previews no longer spike memory, and reuse decoded photos when an option changes.
  Thanks @mattsivak. (⇠ #1887, ⇠ #2010)
- **Photo Merge ▸ Focus Stack:** photos focused at different distances merge into one DNG that is sharp throughout.
  Thanks @dev-null-undefined and @mattsivak. (⇠ #1732, ⇠ #1888)
- **Interactive histogram:** drag the histogram's five tonal zones to move Blacks, Shadows, Exposure, Highlights
  and Whites, as in Lightroom Classic. Thanks @deunderscorepaul. Fork #207. (no PR: Classic's histogram)

## Develop

- **History groups and editing a past step,** as above. Fork #215. (no PR)
- **Interactive histogram,** as above. Fork #207. (no PR)
- **Kelvin white balance for more cameras:** the Canon PowerShot G1 X Mark III and the Nikon Z5II show Temp in
  Kelvin instead of the relative −100…+100 scale. Fork #205, fixes fork #157. (⇠ #2009, ⇠ #2006)

- **Histogram display modes:** RGB Overlay, Luminance, Separated Channels or Chroma, on a linear or logarithmic
  scale (a single spike no longer flattens the curve). The clipping triangles fill with the colour of the channels
  that clip, and hovering one previews the clipping overlay. Choose from the selector under the plot or its
  right-click menu. Thanks @deunderscorepaul. Fork #210, for fork #206. (no PR: Classic's histogram)

## Photo Merge

- **Merge dialogs remember the last settings for each kind** (HDR, Panorama, HDR Panorama). Thanks @mattsivak.
  (⇠ #1898)
- **Click the merge preview to zoom in, drag to pan.** Thanks @mattsivak. (⇠ #1878)
- **Sharp handheld HDR merges:** full-size and local (parallax) alignment, Lanczos-3 warps, and the reference's
  finest detail kept where it is well exposed. Thanks @mattsivak. (⇠ #1887)
- **Focus Stack,** as above. Thanks @dev-null-undefined and @mattsivak. (⇠ #1732, ⇠ #1888)
- **HDR Panorama without the memory spike:** brackets are merged one at a time, raws with gain maps are binned for
  previews, and changing an option reuses already-decoded photos. Thanks @mattsivak. (⇠ #2010)
- **Repeating an identical HDR merge reuses the existing result** instead of writing a duplicate file; your edits
  and stack are left as they are. Thanks @bogusyogi. (⇠ #435)
- **A photo selected twice is merged once.** Thanks @endthestart. (⇠ #1959)

## Library

- **Folders inside the library can be renamed again:** Rename Folder… was refused for any folder below the library
  folder, not just the library folder itself, and the dialog closed without saying why. It now renames, and a
  failure shows a message. Fork #209, fixes fork #200. (no PR: fork issue)

## Display

- **No more dark, over-contrasty window on SDR monitors (Windows):** the HDR (scRGB) window surface is now used
  only when the display is actually in HDR mode. On an SDR monitor the window looked too dark until part of it was
  dragged under the taskbar. If you switch Windows HDR on while the app is open, it applies at the next start.
  Fork #223, fixes fork #147. (↑ #1700, added to that open PR)

## Fixes

- **Tests no longer leak into your settings folder:** end-to-end tests ignore an inherited `<PREFIX>_CONFIG_DIR`,
  so the MCP session test no longer leaves an Immich account behind and fails on the next run. Thanks
  @clydecbrown. Fork #212, fixes fork #167. (no PR: fork issue)
- **The histogram's display selector has an accessible name** for screen readers. Fork #226. (no PR: Classic's
  histogram)
