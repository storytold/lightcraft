- **Filter Bar** (`Shift+F`, or `\` in the grids): rating (at least / exactly / at most), pick or reject flag, colour labels, file type, edited or not, camera, lens, keyword, people, and — once the [Image Quality Scanner](../quality-scanner/) has scored something — the quality verdict (accepted, to review, rejected, not scanned) with a score floor. Counts show beside flags and labels. Click several colour swatches to show photos with any of them; the hollow swatch at the end shows the photos without a label; the **Library ▸ Filter by Color Label** menu has a **No Label** row, and searching `label:none` finds the same photos.
- **Metadata columns**: the column switch shows up to six lists (Date, Camera, Lens, Label, Keyword, People, Flag, Rating, File Type, plus ISO, focal length, Aperture and Shutter Speed) with counts and a search box each.
- **Enable Filters** (`Cmd/Ctrl+L`) switches the filter off and on; **Clear** resets it. The filter stays when you change collections.
- **Presets** (filter bar): save, apply and delete filter presets. **Save as Smart Collection…** keeps the filter as a collection.
- **Search Photos** box (`Cmd/Ctrl+F`): text over names, titles, keywords and more. **AI** turns it into a semantic search ("sunset over water") when an image-text model is installed.
- **Advanced Search…** (**Library** menu, `Cmd/Ctrl+Shift+F`): a panel of structured fields in collapsible groups: words, file and collection, properties (size, rating, colour label, aspect), caption and title, camera information (camera, lens, focal length, ISO, shutter speed, aperture), location (GPS), duration, faces. **Search** shows the matches as a filtered grid.
  - **Codec** and **Frame rate** are listed but not supported yet; the inputs are disabled.
  - **Enter Full Screen** moved to `F11` (`Cmd+Ctrl+F` on macOS) to free the shortcut.
- **Search chips** below it in Modern, such as `3+` and `Picks`, are quick filters.
- **Sort** (bottom bar, **View ▸ Sort**): capture date, import date, edit date, file name, rating, file size, random, custom order, or quality (photos no scan scored come first ascending); ascending or descending; grouping by day, month or year.
- Stacked photos and virtual copies honour the filter; **Hide Rejected Photos** filters rejects out.
- **Find Similar Photos** filters to look-alikes; **Clear Filters** returns.

<Aside type="note" title="Modern layout">
  Filter (funnel icon) and the search box with chips are on screen. **Advanced Search…**: ☰ ▸ **Library**. Sort and grid style: **View ▸ Sort**.
