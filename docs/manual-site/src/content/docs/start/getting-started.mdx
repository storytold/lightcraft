The first time you start the app, the **Welcome** window creates or opens your library. A short guide follows it, one
page at a time. **Back**, **Next** and **Skip** are on every page; **Esc** skips. Open it again at any time with
**Help ▸ Getting Started…**.

## 1. Choose AI features

<Shot name="getting-started-ai" alt="The AI features page of the Getting Started guide" menu="Help ▸ Getting Started…" />

- Each AI feature runs on your computer: a one-time download, plus memory while it works. Without a graphics card it
  is slow.
- The page shows your computer's memory and graphics card, and each feature's download size, licence and memory use.
- What is ticked at first depends on the computer: nothing under 8 GB of memory; AI Denoise, Super Resolution, Object
  masks and lens profiles from 8 GB; Subject and Sky masks from 16 GB with a graphics card.
- **Face recognition** and **AI search** are never ticked for you: they scan the whole library in the background.
- Nothing downloads until you click **Finish**. The downloads then run in the background, in the activity list.
- A version without a feature (the web version, for example) doesn't list it.
- Change this later in **Settings ▸ AI Models**, **AI Denoise** and **Faces**. Generative Fill is an online service,
  set up in **Settings ▸ Generative Fill**.

## 2. Interface

<Shot name="getting-started-interface" alt="The Interface page of the Getting Started guide" menu="Help ▸ Getting Started…" />

- **Layout**: [Classic, Modern or Compact](../layouts/).
- **Appearance**: follow the system, light or dark, and the colour scheme (Charcoal, Midnight, Silver, Paper).
- **Text size**, **Language** and **Grading Mode** ([Witchcraft or Eboda](../../develop/colour/#two-grading-modes)).
- Every change shows at once. **Undo these changes** puts back how the app looked when the guide opened.

## 3. Key settings

- Ask which library to open each time the app starts.
- Check for updates when the app starts.
- Write changes into XMP sidecars automatically, so other apps see your ratings, keywords and edits.
- Reduce motion.
- These are the same settings as in **Settings**; raw defaults and the memory budget stay in **Settings ▸ Import**
  and **Settings ▸ Performance**.

## 4. Tour

<Shot name="getting-started-tour" alt="A tour page of the Getting Started guide" menu="Help ▸ Getting Started…" />

One page each for [Import](../../library/import/), [Library](../../library/browse/),
[Develop](../../develop/basic/), [AI tools](../../ai/), Map, Book, Slideshow, Print and Web, and
[Export and sync](../../output/export/). **Read more in the manual** opens the page for that module.

## 5. Finish

The last page lists what will download. **Finish** starts those downloads; **Skip** on any page closes the guide
without downloading anything. Either way the guide doesn't open by itself again.
