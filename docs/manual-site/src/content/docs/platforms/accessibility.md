Partial.

- **Desktop** exposes an accessibility tree: VoiceOver (macOS), Narrator (Windows), Orca (Linux).
- Buttons, sliders, fields, thumbnails (name, rating, flag, label), the Map, Book, Slideshow, Print and Web panels, Metadata and Navigator are named.
- **Tab** and **Shift+Tab** move through each module's panels.
- Arrow keys nudge the crop frame and the selected spot (1 %, Shift for 10 %).
- **Handles on the photo** take the keyboard focus: crop corners and edges, spots, a new spot, red-eye circles, gradient handles and mask pins. A screen reader reads each one's name and place; the arrow keys move it (Shift: further), Return on a mask pin selects its mask.
- **The brush by keyboard**: with the Brush picked, focus the brush handle on the photo (it starts at the centre). **Return** or **Space** puts the brush down and paints a dab; while it is down each arrow press paints a stroke to the new place; **Return** again lifts it, and the arrows then only move it. Each press is one undo step, with the panel's size, feather, flow and Erase.
- Not yet: no screen-reader audit by blind users yet; a few shared widgets (filmstrip cells, search field, keyword fields, Quick Develop steppers) lack names.
- The **web build** has no screen reader support.
- Shortcuts are listed in **Help ▸ Keyboard Shortcuts** and can be changed.
