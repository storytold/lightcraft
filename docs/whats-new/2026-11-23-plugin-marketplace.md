### Plug-in Marketplace

- **File ▸ Plug-ins ▸ Plug-in Marketplace…** lists plug-ins and pixel filters you can install without finding a file first: search, **Install**, **Update**, **Update All** and **Remove**. It always shows each plug-in's newest release.
- Each entry is **Vetted** (a marketplace maintainer read its source) or **Community** (automatic checks only). Community entries are hidden until you tick **Show community plug-ins (higher risk)**.
- An entry's page shows which systems it works on, what it may ask you for, who signed it and where it comes from, before anything is downloaded. Installing allows nothing: a plug-in asks the first time it needs a permission.
- **Update installed plug-ins automatically** is off until you turn it on. An update then installs by itself only when it asks for nothing new and is signed as the version you have; anything else waits for you.
