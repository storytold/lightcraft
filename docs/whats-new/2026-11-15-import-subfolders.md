### Folder import includes its sub-folders

- Browsing a folder for the first time (the Import tab, Local, `library.browse`) now starts with **Include subfolders** on, so importing from a main folder takes the photos in its sub-folders too (before, only the Import dialog did; the tab's first browse was flat with no way to change it). Re-browsing the same folder keeps the choice you made.
- The Import tab's bar has an **Include subfolders** checkbox, like the Import dialog and the Local folder header; changing it re-browses the folder at once, and the import that follows takes what the browse shows.
