### Windows updates restart the app again
- Installing an update on Windows again does what it says: the app quits, the installer runs, and the app starts again when the installer is done (when Windows wants a restart as part of it, the app starts after that restart).
- Start-menu shortcuts, and taskbar entries pinned from them, keep working after updates: the shortcut is now a plain link to the installed program, not an installer advertisement that every update invalidates.
