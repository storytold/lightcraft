### Lightroom catalogs open in minutes
- Importing a Lightroom catalog no longer waits for every original file to be read: the photos, with their ratings, keywords, collections and edits, appear as soon as the catalog is read (issue #1303).
- The original files are then read in the background, as one **Reading originals** row on the activity stack that you can stop. What it has read is kept; the rest is read the next time the library opens, and photos on a disconnected drive are tried again then.
