### Plug-in updates

- A signed plug-in whose author publishes an update feed has **Check for updates** on its page in the Plug-in Manager, off until you turn it on. Opening the Plug-in Manager then checks for a newer version, at most once a day; nothing checks while it's closed.
- An update shows its version, the author's short note, a changelog link and the permissions it adds. **Update** installs it like a hand install: new permissions aren't granted (it asks when it needs one), and **Go Back to Version X** returns to the one you had. If the file asks for more than its feed said, it installs only on your **Update Anyway**.
