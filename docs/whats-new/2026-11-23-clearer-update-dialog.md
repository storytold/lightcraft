### A clearer update dialog
- Help ▸ Check for Updates… says how long ago it last checked ("Last checked 5 minutes ago") and keeps that line up to date while the window is open.
- One sentence now says what Download does: it downloads the new version, verifies that it was signed by the {app} authors, and offers to install it (or opens its folder where {app} can't install it).
