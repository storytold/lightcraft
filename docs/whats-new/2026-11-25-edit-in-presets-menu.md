### More editors in the Edit In menu
- **Edit In Presets** (Photo → Edit In) now puts every saved editor in the Edit In menu, each with its own items.
- Each preset has an **Edit In Menu** setting: Lightroom's choices (Edit a Copy with Adjustments, Edit a Copy, Edit Original, or Open Source File on a raw), one **Edit in** item (a raw developer such as DxO PhotoLab), or up to 8 items of your own with their arguments (a denoiser's Process with the Latest Settings, Process Immediately, Preview and Process).
- An item takes the whole selection: the files are made first, then one start of the editor gets them all.
