### The command-line tool comes inside the Mac app
- On macOS the command-line tool is now inside the app instead of a separate download, and updates with it. The manual's Install page shows how to run it from Terminal.
- The app and the tool share one copy of the fonts for Chinese, Japanese, Korean, Arabic and other scripts, so the download is smaller.
- If one of those fonts is missing or damaged, the app says which one and how to get it back, instead of showing empty boxes.
