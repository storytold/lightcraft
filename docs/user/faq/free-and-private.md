Yes, it is free. LightCraft Classic is open source under the MIT licence. It needs no account, no cloud service and no subscription, and it sends no telemetry.

## Where are my photos and edits kept?

On your computer. Your library lives in a folder you choose, by default `~/Pictures/LightCraft Classic Library`. Edits are non-destructive, so your original files are never touched. The catalog is a log of human-readable operations that you can back up. Use **File** > **Back Up Library…** to make a backup.

## Which systems does it run on?

LightCraft Classic runs on Windows, macOS and Linux, and in a web browser. See [Install LightCraft Classic](../getting-started/install.md).

## Is it finished?

No. LightCraft Classic is in alpha. Some things from Adobe Lightroom are not there yet, such as on-screen HDR display, video and the Print, Book and Map modules. The project's [roadmap](https://github.com/emmertex/lightcraft-classic/blob/main/ROADMAP.md) lists what is missing.
