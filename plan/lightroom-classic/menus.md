# Menu map

Where commands live in Lightroom Classic, summarised in our own words so our menus can put things in familiar
places. The menu bar changes with the module: the first menus (application, File, Edit) are shared, the middle
ones belong to the module, and View / Window / Help are shared again. Rows in `docs/parity.md` use `MENU-` ids
for the menu items we track.

## Shared menus

| Menu | What it contains |
|---|---|
| Application (macOS) | about, preferences, catalog settings, hide/quit |
| File | new / open / open recent / optimise catalog; import; tethered capture; auto import; import from another catalog; export (dialog, with previous, presets); export as catalog; email; plug-in manager and plug-in extras; show quick collection, save / clear quick collection; library filters; page setup and print (in Print) |
| Edit | undo / redo; select all / none / inverse, select flagged / unflagged / rated / labelled; spelling and special characters; preferences and catalog settings (Windows) |
| View | toggle the loupe info overlays, grid view options, lights out, screen modes, zoom, secondary display, show/hide toolbar and filter bar |
| Window | module switching with its shortcuts, lights out, screen mode, secondary display, panel visibility |
| Help | module help, module shortcuts overlay, plug-in help, updates, system info |

## Module menus

| Module | Menus and what they hold |
|---|---|
| Library | **Library:** new collection / set / smart collection, new folder, find, filter by…, refine photos, rename, convert to DNG, find missing, synchronise folder, previews (build / discard). **Photo:** add to quick collection, show in file manager, edit in external editor, stacking, people, create virtual copy, rotate / flip, set flag / rating / colour label, auto advance, edit capture time, update DNG previews, read / save metadata, remove photos. **Metadata:** keyword sets, enable painting, copy / paste metadata, sync metadata, edit metadata presets, show metadata for target photo only, read / save metadata, update DNG previews. |
| Develop | **Develop:** new snapshot, new preset / preset folder, reset, set default settings, copy / paste / sync settings, auto sync, previous, match total exposures, enable auto white balance and auto tone, tools (crop, remove, red eye, masking). **Photo:** as in Library, plus photo merge (HDR, panorama, HDR panorama) and Enhance. **Settings:** copy, paste, sync, reset, convert to B&W, soft proofing toggle. **Tools:** crop guide overlay, tool overlay, and the targeted adjustment tools. |
| Map | **Map:** map style, find location, saved locations, tracklog (load, auto-tag, offset), show/hide filter bar. |
| Book | **Book:** new book, book settings, add / remove pages, clear layout, guides, export to PDF / JPEG. |
| Slideshow | **Slide:** new template / template folder, play, preview, export to PDF / JPEG / video. **Play:** start, go to next / previous slide, end. |
| Print | **Print:** new template / folder, page setup, print settings, print / print one. |
| Web | **Web:** new template / folder, reload, preview in browser, export, upload, export & upload. |

## Context menus

- **Thumbnail** (grid / filmstrip): rating, flag, label, add to collection, stacking, create virtual copy, develop
  settings, metadata presets, rotate, metadata, export, show in folder, remove.
- **Folder / collection rows:** create, rename, remove, set as target collection, export this folder as a catalog,
  synchronise, show in file manager, update folder location.
- **Preset / snapshot / history rows:** apply, update with current settings, rename, delete, export, copy step
  settings to before.
